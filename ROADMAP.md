# Roadmap

Ideas for later versions, not yet scheduled. Each has to keep the [design requirements](README.md#design-requirements).

## Add to an existing session

Pick an existing session and add level folders or shot folders to it with the same naming rules, for when a third day or extra looks are added mid-job. It must read the session's naming back (or store it in the session) so new folders match the old ones, and flag clashes with folders already there.

## Shot list export

Save the shot folders, with their pasted names (SKUs, looks, talent), as a CSV or text file in the documents folder, for the crew, the stylist or the client to sign off and tick off during the shoot.

## Next capture folder script

A companion script, bound to a key in Capture One, that sets the capture folder to the next one in the session's order (and back). The session is already built in that order, so on set it saves finding each shot folder in the Library by hand.
